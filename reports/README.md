# Project Report

Put the **sanitized** report here as `project-report.pdf`.

The original report contains a database password, the RDS endpoint and the AWS account ID (in code snippets and screenshots). Do **not** upload it as-is:

1. Edit the PDF (or the source document) to remove the password, endpoint and account ID.
2. Export a fresh PDF and check it with a text search for `password`, `rds.amazonaws.com` and your account ID.
3. Save it as `reports/project-report.pdf`.
4. Rotate the RDS password anyway, since it has already existed in a shared document.
